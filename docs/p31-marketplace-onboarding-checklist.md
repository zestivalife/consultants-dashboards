# P31 real-consultant onboarding checklist

This checklist prepares real consultant records without publishing them. Imports and manual entry always begin as `DRAFT`; Super Admin approval and explicit publication remain separate.

| Area | Field/evidence | Required | Super Admin verified | Public | Private |
|---|---|---:|---:|---:|---:|
| Identity | Governed account and active tenant membership | Yes | Yes | No | Yes |
| Public profile | Display name, professional title, profession | Yes | Yes | Yes | No |
| Photo | Private P23 source and approved public derivative | Yes | Yes | Derivative only | Source document |
| Expertise | Specialisations, experience, bio, languages | Yes | Yes | Yes | No |
| Credentials | Qualification, institution and award year | Yes | Yes | Verified projection | Evidence document |
| Registration | Number, issuing body, country and expiry | When applicable | Yes | Policy-selected fields only | Source evidence |
| Services | Active P13 appointment type, duration, mode and enrolment mode | Yes | Yes | Yes | Internal configuration |
| Programmes | Active P12 package/programme | Optional | Yes | If selected | Internal lifecycle |
| Pricing | Public fee | Optional | Yes | If supplied | Billing records |
| Locations | Active P26 location or online configuration | Yes | Yes | Public-safe name/mode | Address and phone unless approved |
| Availability | Active P13 public-safe windows | Yes for booking | No | Weekday/time/timezone | Calendar events and blocked reasons |
| Accepting clients | Current governed status | Yes | No | Yes | No |
| Reviews | Verified engagement eligibility | Optional | Moderated | Published review only | Client identity and moderation notes |

Before submission, confirm the deterministic completeness result is 100%, credential evidence remains private, and every selected service/location/package belongs to the same tenant. Before publication, confirm the exact approved version and repeat the public privacy review.
