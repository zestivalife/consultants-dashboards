# Completion Requirements

The Epic is complete only when:

- Business capability is fully implemented.
- Tests pass.
- Runtime verification succeeds.
- Documentation is updated.
- Delivery documentation is updated.
- No duplicate Sources of Truth exist.
- Code is committed cleanly.

Stop after submitting the Completion Report.

Wait for approval before beginning the next Epic.
